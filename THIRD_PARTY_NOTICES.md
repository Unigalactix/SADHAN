  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Weather values
  are displayed as supplied, with condition codes translated into labels.
- Exchange reference rates: [Frankfurter](https://frankfurter.dev/) /
  European Central Bank. AED is an explicitly labelled estimate using the
  USD peg (3.6725 AED per USD), not an ECB quote.
- YouTube is accessed only through its official player and mobile site.
  YouTube's terms, restrictions, advertising and privacy policy apply.
  SADHAN is not affiliated with or endorsed by YouTube or Google.
- Update metadata and downloads: GitHub Releases.
- Private-browser websites and DuckDuckGo searches make normal web requests.

  not anonymity or a promise of forensic erasure.

## Original games

Snake, Klondike Solitaire, Chess, Pixel Runner, Lane Racer, Rhythm Tiles and
Block Drop are original native implementations using generic game mechanics.
Art and piano tones are generated by SADHAN code. No game ROMs, borrowed
characters, branded artwork or third-party music are bundled.
